MicroNAS

A compact personal cloud storage device that uses MicroSD cards instead of hard drives.

Board
ESP32
Storage
MicroSD cards
Enclosure
3D printed, Fusion 360
Event
CUTC Transform Hackathon 2026

MicroNAS demo

Why

Home NAS devices often cost $200 to $500 and need dedicated hard drives. MicroNAS aims to give private, remotely accessible storage at a fraction of the cost and size.

What I built

  • Designed and 3D modeled the enclosure for printing
  • Built and soldered the full circuit around the ESP32
  • Wrote the ESP32 code that reads and writes MicroSD cards
  • Connected the ESP32 to the web interface
